# dsh-delete-button

为 DeepSeek Harness 增加「删除对话」按钮。

## 安装

```sh
dsh plugin --profile desktop add dsh-delete-button
```

桌面端安装前完全退出应用，安装后重新打开。Web 用户请填你所使用的 profile。

在对话的更多菜单中选择「删除对话」。已归档的对话也可以删除。删除时会一并删除所属子代理的对话，保留独立分叉的对话和项目文件。

## 实现

插件挂接 DSH 内部的 Agent 工厂，取得创建和恢复会话时返回的完整释放句柄。删除时调用宿主的 `dispose()`，由原有生命周期结束执行、释放 PTC 和常驻终端、关闭日志写入，然后清理历史文件和列表记录。

会话恢复和缓存写入也纳入同一流程：删除期间拦截新的恢复和写入请求，等待已经开始的操作结束后清理缓存。删除时机由这些操作的完成信号决定，并不需要固定延时或反复删除目录。

图片和文件附件可能被其他对话共享，因此会保留。其他对话中指向已删除对话的历史链接将失效。
